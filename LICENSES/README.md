# Attribution and license scope

The project extends [DeepGD](https://github.com/yolandalalala/DeepGD). The upstream MIT notice preserved from the source workspace is in [DeepGD-MIT.txt](DeepGD-MIT.txt).

The manuscript authors must confirm the license for their HCTF-GD additions, generated source data, figures, and model weights before public distribution. The upstream notice applies to the covered DeepGD material. See [DATA.md](../docs/DATA.md) for original dataset sources and [BASELINE_SOURCES.md](../docs/BASELINE_SOURCES.md) for external baseline attribution.
